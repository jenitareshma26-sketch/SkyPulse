# SkyPulse 🌦️

A modern and responsive Weather Forecast Application that provides real-time weather information for cities around the world. SkyPulse helps users stay informed about current weather conditions, temperature, humidity, wind speed, and forecasts using live weather data APIs.

## 📌 About the Project

SkyPulse is designed to deliver accurate and up-to-date weather information through a clean and user-friendly interface. Users can search for any city and instantly view detailed weather conditions, making it easy to plan daily activities and travel.

## ✨ Features

- 🌍 Search weather by city name
- 🌡️ Real-time temperature updates
- ☁️ Current weather conditions
- 💧 Humidity information
- 💨 Wind speed details
- 🌅 Sunrise and sunset timings
- 📱 Responsive design
- ⚡ Fast and lightweight interface
- 🔄 Live weather data integration

## 🚀 Installation

### 1. Clone the Repository

```bash
git clone https://github.com/jenitareshma26-sketch/SkyPulse.git
```

### 2. Navigate to the Project Folder

```bash
cd SkyPulse
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Configure API Key

Create a `.env` file and add:

```env
OPENWEATHER_API_KEY=your_api_key_here
```

Get your free API key from OpenWeather.

### 5. Run the Application

```bash
python app.py
```

### 6. Open in Browser

```text
http://127.0.0.1:5000
```

## 📖 How to Use

1. Launch the application.
2. Enter a city name.
3. Click the **Search** button.
4. View current weather details instantly.
5. Check temperature, humidity, wind speed, and weather conditions.
